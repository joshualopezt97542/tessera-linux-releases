# Tessera Linux Early Access — Privacy Notice (Review Before Public Posting)

This notice describes the free Tessera Linux Early Access build published by Case Sensitive Computers, LLC.

The Early Access game does not ask for an account and does not process payment information. It stores game progress locally in a file under your home directory and uses local system preferences for ad frequency.

To display CSC house advertisements, the game requests creative data from a CSC-controlled HTTPS service and artwork from the Case Sensitive Computers website. Hosting and website services may receive normal technical request information, such as the requesting IP address and browser or HTTP client details; the app does not attach a Tessera player identifier to these ad requests. Clicking an advertisement opens the relevant web page in your browser, where that site's privacy practices apply.

There are no third-party advertising network SDKs, no behavioral advertising profiles, no location tracking, and no usage analytics implemented in this Early Access build. There is no in-game account synchronization or cloud save.

You can remove local saved data by deleting `~/.local/share/tessera-linux-early-access/` after quitting Tessera. System preferences may also contain Tessera-specific ad frequency data.

For privacy requests, contact Case Sensitive Computers through https://casesensitivecomputers.com.

**Publication note:** Confirm the company's complete legal contact and retention practices before treating this as a finalized public privacy policy.
